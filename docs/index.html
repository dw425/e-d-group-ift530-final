Running it yourself

The script creates its own database and drops and rebuilds every object inside it, so it can be run repeatedly without cleanup:
sqlcmd -S localhost,1433 -U sa -C -i IFT530_EDGroup_FinalProject.sql
It has been run three times in a row against SQL Server 2025, clean each time, and the row counts are asserted by the script itself.
